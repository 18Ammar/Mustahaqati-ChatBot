# Mustahaqati ChatBot

React app powered by Vite.

## Available Scripts

### `npm install`

Installs project dependencies.

### `npm start`

Runs the app in development mode with Vite.

### `npm run dev`

Runs the same Vite development server as `npm start`.

### `npm run build`

Builds the production app into the `dist` folder.

### `npm run typecheck`

Runs TypeScript validation without emitting files.

### `npm run preview`

Serves the production build locally after running `npm run build`.
